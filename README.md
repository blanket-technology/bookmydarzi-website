# BookMyDarzi - Designed Static Web

A polished, responsive BMD web frontend with hard-coded demo content.

## Run
npm install
npm run dev

Open http://localhost:3000

## Pages
/ - Home
/services - service catalog with search/filter and demo Add button
/cart - cart
/checkout - checkout
/orders - orders
/profile - profile

## Customize
All content is intentionally hard-coded so you can replace it directly with your BMD API data later. Tailwind CSS is used throughout the UI.
